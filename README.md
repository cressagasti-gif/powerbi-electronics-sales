## EN

A Power BI course project analysing **electronics and home appliance sales**
across different stores and zones of the country over a period of time.

### What it contains

| Report page | Contents |
|---|---|
| Report 1 | Sales overview |
| Report 2 | Breakdown by store |
| Report 3 | Breakdown by zone and time period |

### How to open

The deliverable is a `.pbix` file, so it needs Power BI Desktop (Windows).

1. Download [`Tarea Procesamiento de Datos.pbix`](Tarea%20Procesamiento%20de%20Datos.pbix)
2. Open it in **Power BI Desktop**
3. Explore the three report pages

> GitHub cannot render `.pbix` files in the browser — they are binary project
> packages, not images. You have to open them locally to see the visuals.

### What I learned

- Turning raw sales data into a report someone can actually read
- Comparing performance across a store hierarchy and a geographic hierarchy
- Slicing the same measure by time without duplicating visuals

## ES

Proyecto de curso en Power BI que analiza ventas de **electrónica y
electrodomésticos** en distintas tiendas y zonas del país a lo largo de un
período de tiempo.

### Qué contiene

| Página | Contenido |
|---|---|
| Reporte 1 | Panorama general de ventas |
| Reporte 2 | Desglose por tienda |
| Reporte 3 | Desglose por zona y período |

### Cómo abrirlo

El entregable es un archivo `.pbix`, así que necesita **Power BI Desktop** (Windows).

1. Descargá [`Tarea Procesamiento de Datos.pbix`](Tarea%20Procesamiento%20de%20Datos.pbix)
2. Abrilo con **Power BI Desktop**
3. Explorá las tres páginas del reporte

> GitHub no puede mostrar archivos `.pbix` en el navegador: son paquetes de
> proyecto binarios, no imágenes. Hay que abrirlos localmente para ver los
> gráficos.

### Qué aprendí

- Convertir datos de ventas crudos en un reporte que alguien pueda leer de verdad
- Comparar el desempeño entre una jerarquía de tiendas y una jerarquía geográfica
- Filtrar la misma medida por tiempo sin duplicar visuales
